# AI 单日考勤结果的中文展示

## 目标和范围

员工在 AI 助手查询本人单日考勤时，回答中应显示可读的中文日结果，例如“迟到且早退”，并保留实际迟到、早退和请假数值。当前后端将 `LATE_AND_EARLY` 等内部状态码直接写入回答，不利于阅读。

本次仅调整 Java 根据真实工具回执生成的事实回答；日结果仍由原考勤服务计算，工具回执中的 `status` 和其他字段保持不变，权限、模型工具参数和数据库结构不变。历史已保存回答不会批量重写；之后的新回答使用中文。

## 业务口径与验收

中文标签与考勤工作台的既有 `dayLabel` 对齐：优先识别受限，缺签到或签退时显示“待核对 / 缺卡”，其余已知状态按现有对应中文展示。受限数据只说明无法查看，不将缺失的数值编造成零。状态未知、缺失或格式异常时显示“待核对”，避免把内部未知值当成明确考勤结论；这是对前端当前未知状态原样展示的有意安全兜底。只改变展示，不把未知状态推断成正常或缺卡。

验收采用不启动数据库、不调用模型的单元测试，覆盖真实迟到且早退、缺卡优先级、受限优先级、未知及缺失值，核对日期和数值仍来自原始回执；同时保留既有接口与工具权限测试供后续整体回归。真实人脸效果和模型理解能力不在本次验收范围。
