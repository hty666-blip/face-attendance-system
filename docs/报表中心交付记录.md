# 月度报表中心交付记录

日期：2026-10-26。对应《报表中心设计.md》。保留现有 Vue、Spring Boot 2.7、Java 8 语言目标、MySQL 与 POI，验证使用 JDK17。

## 完成功能与口径

考勤工作台新增“月度报表与导出”：员工预览本人月报；主管/管理员明确选择一个有权访问的部门，预览该部门当前在职员工档案人员的月报。页面展示汇总、逐人统计、每日事件与规则依据，可创建、查看、取消导出任务并鉴权下载 Excel。未知创建结果保留原条件与 requestKey，按登录用户隔离恢复；采用手动刷新，不进行后台轮询。

部门最多50名员工，超出明确拒绝。它是当前人员口径，调出/停用人员不自动纳入；未知、混合或其他部门历史日均不计入，即使管理员生成也不混入别的部门。历史组织花名册尚未还原，不把受限日补零为正常。

原工作台与月报复用 `AttendanceService` 的日结果和统计函数。每份报告在独立、只读的 REPEATABLE_READ 事务读取，固定一次北京时间作为日状态与统计基准；预览不写入日快照。文件记录生成时间、计算版本、规则编号、原始事件来源及未结算标记。文件生成后批准的事实可改变新预览，旧文件保留生成时的内容，需要更新时明确创建新版本；报表没有封账或工资结算含义。

预览需要 records.list，创建/执行/下载还需要 records.export。V004 显式给内置 employee、manager 角色绑定受限导出权限；自定义角色不自动增加。任务始终只有创建者可读、取消、下载，管理员也不能通过编号读取他人的文件。人员范围及每日可见范围通过指纹记录，执行、发布及下载时重新检查；权限、人员或归属变化可能要求重建任务。

## 请求链路与恢复

浏览器预览 → Java 从数据库加载当前身份与权限 → 共用日结果组织白名单 → 用户创建任务 → 短事务加用户行锁、绑定请求内容并保存 QUEUED → 后台原子领取租约 → 独立事务读取一致报告 → POI 生成文件 → 再次验证范围 → 租约匹配时把文件与 READY 状态一起写入。

后台按 ownerId 重新加载身份，不模拟 HTTP 登录或传递浏览器令牌。身份、部门、可见范围不接受浏览器指定。报表只包含必要姓名、用户名、编号、日结果与统计，不输出人脸、密文、联系方式、地址或口令。

默认启动1秒后扫描，每轮处理一个任务，完成后15秒继续扫描。租约5分钟，最多3次尝试；恢复过期租约时清除旧编号，再次领取使用新编号，旧工作者不能覆盖取消或新的结果。每人默认最多3个未完成任务。文件最大8MiB、有效期24小时，过期清空内容并保留元数据。

小规模文件保存于专用 MySQL MEDIUMBLOB，和 READY 同一次更新，避免本地文件与状态双写、共享头像目录或多实例文件不一致；代价是数据库体积和下载内存。未增加消息队列或对象存储。`REPORT_SCHEDULING_ENABLED=false` 可停调度而保留任务，`REPORT_MAX_ACTIVE_JOBS` 配置未完成任务上限。

## 启用与演示

1. 已完成 V003 的旧库先备份、在副本执行 `database/migrations/V004__attendance_exports.sql`；更早版本依次执行尚缺迁移。新空库只执行完整 schema、seed，不重复执行迁移。V004 不修改旧事件、旧请假或既有规则。
2. 启动后端，保持默认调度开启。员工打开“月度报表与导出”，选择月份预览，核对与“我的月度考勤”的数值。
3. 点击“创建导出任务”，刷新至可下载，下载并检查说明、人员汇总、每日明细；主管选择部门再重复，核对仅本部门当前员工及可见历史。
4. 撤销导出权限或调整人员范围，再访问既有文件应拒绝；恢复权限后按新范围重新创建。取消演示须在排队/生成中执行，终态不能取消。
5. 重启恢复、租约过期、权限并发等故障演示只使用测试环境。恢复库时同步恢复匹配版本与完整备份；MySQL DDL 隐式提交，不能通过源码回退或事务撤销 V004。文件含个人业务数据，数据库备份需要按业务数据保护。

## 已知限制与后续

当前只支持单月、本人/一个当前部门、最多50名在职员工，不包含完整历史组织、跨部门总报表、定稿封账或工资结算。共用日结果查询还未针对大部门批量优化，未做吞吐/内存压测，不能由小规模联调推断生产规模。

下载会重新生成当前可见范围用于验证，因此当前数据量下会额外查询；未来应在权限证明与组织历史明确后优化。后台是单体串行扫描，队列较长会等待；任务元数据持续保留，尚无长期归档策略。文件在应用与数据库层受限，不等于新增了数据库静态加密。

下一阶段把本轮报表接口作为统一工具接入 LangChain AI。未配置或验证真实模型时，不能将 Mock 工具链路宣称为真实 AI 效果。
