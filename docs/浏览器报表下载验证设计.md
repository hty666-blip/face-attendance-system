# 浏览器报表下载验证

目标用户为需要从考勤助手或报表中心取得 Excel 的员工与主管。本次验证登录、创建导出任务、等待就绪、点击下载和核对文件的完整链路；不改报表计算和权限规则。

使用单独新建的本机临时数据库及合成账号，沿用明确标记的 Mock 助手，避免为验证文件下载产生额外模型费用。保留之前用户体验环境及其本地资料，不连接原始数据库。新环境与原有服务使用独立端口、随机内部凭据和可核对的进程及容器身份。

验收条件为浏览器真实登录并点击导出与下载；能够取得浏览器保存的文件后，检查三个页签及统计与报表一致，并验证其他用户不能下载。若浏览器工具不提供下载文件路径，只记录可观察证据，不将 HTTP 下载验证等同于浏览器实际落盘。完成后仅回收本轮测试资源，记录结果和未解决的问题。
