# 独立合成演示环境设计

日期：2026-10-27。前置为已推送并通过四项CI的助手首版64ad652。本轮补齐原计划的可重复启动、脱敏演示数据和5～10分钟演示交付；没有真实模型Key，不扩大AI写操作。

目标用户是首次复现项目的作者与评审者。当前正常开发启动器会读取开发数据库和已有密钥，不适合无原库副本的快速演示。演示入口从全新的本地MySQL容器开始，提供管理员、两个部门主管、两个员工，按实际业务Service完成合成审批、考勤汇总、明确Mock对话和真实XLSX导出。

首版仅支持Windows PowerShell 5.1/7及已准备好的本项目依赖、boot.jar、Docker Desktop本地Linux引擎和mysql:8.4镜像。启动器不安装全局依赖、不自动下载镜像或模型、不读取原SQL、不公开部署。人脸功能关闭，合成事件通过补卡申请及审批产生，不声称真实人脸采集或真实模型理解。

## 资源和边界

- 新增scripts/start-demo.ps1、stop-demo.ps1、demo-common.ps1；直接启动java.exe、项目.venv python.exe和node.exe，不通过npm或额外shell子树。父启动器保持前台，Ctrl+C或组件退出时只回收本轮资源。
- 运行资料位于新建的`.local/demo/<32位runId>/`，禁止复用已有运行目录，拒绝越界和重解析路径。凭据与日志只在该目录，限制当前用户及SYSTEM访问。停止保留本地日志，删除的是经过验证、无数据卷的本轮临时容器。
- 默认端口：MySQL13307、Java19091、Python8011、Vite7001；全部127.0.0.1，全部严格预检，冲突立即失败，不杀占用者、不自动漂移。
- Docker context必须明确且端点为本机named pipe；拒绝远端Docker。容器随机名称、带项目路径及runId标签；停止校验不可变ID、名称与标签，不按名称前缀清理其他容器。mysql镜像声明了数据VOLUME，因此显式采用固定`/var/lib/mysql`的512MiB tmpfs，拒绝所有bind、volume和其他挂载；不留下匿名数据卷。内存上限768MiB，适用于小型合成演示。
- 子进程环境从空白构造，仅保留必要系统路径，显式设置独立DB_URL/DB_PASSWORD/JWT/BOOTSTRAP与助手内部token。忽略父DB_*、SPRING_*、JAVA_TOOL_OPTIONS、模型Key/URL/Provider、人脸和追踪环境。Java只加载JAR内application.yml并绑定127.0.0.1；工作目录使用本轮目录，文件不落入原files目录。
- Python固定mock，独立内部token，不读取共享.local密钥；Java FACE_ENABLED=false。Vite采用独立demo配置和本轮空env目录，覆盖VITE_SERVER_URL及本地严格端口，避免front/.env.local改变演示目标。
- 停止进程需PID、创建时间与完整可执行路径同时匹配；不按端口、进程名批量终止。重复停止幂等，所有权不符时拒绝并保留该资源。

## 私密运行契约

`manifest.json`仅在受保护运行目录：formatVersion=`attendance-demo-v1`、runId、projectRoot、dockerContext、containerId/containerName、ports(database/backend/assistant/frontend)、database(name=`attendance_demo`,username=`root`,password)、bootstrap(username/password)、assistantToken、jwtSecret、processes(role/pid/startTimeUtcTicks/executablePath)、ready/ended及可选stopRequested。公开stop先原子发布停止请求，父守护按正常退出进入finally；意外组件退出仍保留错误。并发清理只在重新确认同一不可变ID或进程已消失后认作已停止，不把引擎故障或身份不符吞成成功。

`scripts/demo/seed-data.py --manifest <绝对路径>`由启动器调用，先验证路径、版本、runId、Docker本地端点、容器ID/标签及仅固定tmpfs，再从该容器读取/修改固定attendance_demo库。仅向manifest生成的127.0.0.1后端登录；随机bootstrap身份能防止误连已有后端。该脚本不接收任意数据库URL、数据库名、容器或账号参数，不打印凭据及令牌。

合成初始化写出`accounts.json`（各演示账号及随机密码，不保存JWT）和`demo-context.json`（演示月份、过去工作日、部门/用户ID及合成标记）。数据初始化仅允许一次；已完成不覆盖，不重置已有运行。SQL仅用于新环境的规则生效日、账号创建日、已知日快照夹具；补卡/请假及批准通过实际API，事件来源为CORRECTION，保留申请和审批记录。

## 验收

启动与停止的安全测试验证环境隔离、端口冲突、路径/标签/PID复用拒绝及幂等，不安装测试框架。实际隔离演示验证两部门/三角色、合成批准链路、月报与助手同口径、本人/跨部门权限、真实导出READY及鉴权下载、停止释放端口及回收本轮容器。所有结果区分合成数据、Mock与真实业务执行；原库和现有密钥文件保持不变。

这是一套本机复现工具，不是部署平台、生产初始化脚本或吞吐验证。真实人脸样本、模型评测、组织历史重建及自动数据保留均不在本轮范围。
