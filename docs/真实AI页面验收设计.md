日期：2026-10-27。前置提交 `a1270c8` 已在独立合成库完成 DeepSeek 本人汇总和部门导出接口联调。本阶段把验收推进到员工和主管实际网页操作，不重复开发已有四工具。

目标用户为查看本人考勤的员工、查看和导出当前授权部门报表的主管。流程为实际登录 → 考勤工作台AI助手 → 新会话并发送明确问题 → 核对真实MODEL工具回执和来源 → 到报表中心查看任务并下载文件。

首版范围是网页上的本人月汇总、本人单日解释、明确部门导出和本人导出任务状态四个功能，补测缺少条件的澄清、扩大范围的请求，以及超时或模型服务不可用后的提示。模型只计划，Java权限、统计口径和幂等规则保持不变。发现实际缺陷后做最小修复并补核心风险回归，不扩展为审批、RAG、流式输出或数据保留开发。

验收仅新建本机独立合成库、随机凭据和独立端口；人脸关闭，不接触原始数据库，不将模型Key交给Java、网页或Git。真实模型请求在出站前持久占用预算，本轮最多12次，不自动重试、不重置预算；超时/不可用可使用明确标注的本地故障注入验证页面恢复，不把故障注入称为真实DeepSeek故障或模型效果。既有一键演示继续强制Mock。

验收要求：四工具经网页发起并显示可核对的实际回执，日解释与合成15分钟迟到/早退口径一致；部门导出只产生一份对应任务，下载文件与报表一致；模糊条件先澄清、扩大权限不执行有效业务；等待期间防重复发送、失败后能核对历史；桌面和窄屏没有关键内容溢出。保存脱敏操作、运行状态、调用数和token证据，不保存Key或模型思维。结束后只回收本轮完整身份匹配的进程和tmpfs容器，确认原配置未改。

本阶段小样本只证明指定页面链路，不构成独立保留集准确率、生产稳定性、人脸识别效果或性能结论。
