# 真实 AI 页面验收交付记录

日期：2026-10-27。本轮面向使用网页核对考勤和生成月报的员工、主管，验证既有 AI 助手能否从实际登录、自然语言提问走到真实业务回执。延续现有 Vue、Spring Boot、MySQL、Python 和 LangChain 技术，不增加新业务工具。

四个工具均已通过真实模型和网页操作验收，权限拒绝、模糊条件澄清及本地注入超时的页面状态也已核对。受控 HTTP 鉴权下载取得了正确的 XLSX；网页点击下载后的自动化下载事件超时，尚未确认浏览器最终存盘，不能将本轮描述为“浏览器下载完整闭环已通过”。

## 范围与隔离方式

本轮运行编号为 `eb773e97e46b4fa4872454e027734986`。使用新建的本机临时合成数据库，在网页分别实际登录员工、研发部主管和另一部门主管。账号、部门、请假、补卡和考勤均为独立验证资料，不代表真实人员或真实出勤。

数据库使用 tmpfs；服务仅在本机端口运行。没有连接或修改使用方原始数据库，没有使用原有用户账号，没有发送真人脸或原始员工数据。浏览器策略拒绝通过 `file://` 打开合成账号资料后，改用仅存在于本轮独立库中的合成测试登录资料；这些资料已随临时库销毁，不在文档或公开仓库记录密码、token、模型 Key 或内部令牌。

真实模型配置和独立运行资料保持本地私密。默认演示入口仍强制 Mock，本轮真实模型验收没有改变原演示的凭据隔离与模式说明。

## 请求链路与业务约束

用户在登录页提交合成账号，由 Java 登录接口建立真实会话。进入考勤工作台的“AI助手”后，新建会话、输入问题并点击“发送问题”。Java保存用户问题及固定请求编号，以当前身份生成可选部门和工具权限，将有限上下文交给 Python。Python经 LangChain 请求真实 DeepSeek，返回结构化工具建议；Java再次检查身份、参数、权限和预算，调用已有考勤、月报或导出服务并保存实际回执。

工具结果继续参与后续计划，直到本轮结束。事实回答、统计、导出编号及成功状态由 Java根据实际回执生成，模型自由文本不能替代业务执行。模型不持有用户 JWT、不访问业务数据库，也不能自行决定可信部门范围。API Key 只用于 Python模型进程，Java使用独立内部令牌访问能力服务。

页面展示实际工具标题、执行状态、来源、条件和可展开的服务端回执。导出工具成功只表示任务已创建；文件是否可用以报表中心或任务状态工具的 `READY` 回执为准。原请求恢复使用固定编号查询，不能因结果未知而无条件新建任务。

## 超时分类修复与故障注入

验收前修复 Java内部能力客户端把模型超时统一归为服务不可用的问题。现在只有受控的 HTTP `504` 且顶层字符串错误码精确为 `MODEL_TIMEOUT`，或实际 socket超时，才映射为模型超时；连接拒绝及其他错误继续区分为服务不可用。成功与错误响应都先按 200 KiB上限读取，先关闭正文流再由客户端清理，避免错误处理阶段无界读取响应。

助手服务将 `MODEL_TIMEOUT` 保存为终态 `TIMED_OUT`，页面显示“处理超时”，并保留原请求和已经提交的工具回执。模型等待仍在事务之外；超时不会自动重放工具或再创建导出。

本轮通过本地故障注入，在网页实际触发一次 `TIMED_OUT / MODEL_TIMEOUT`，该轮没有业务工具、没有真实模型调用。**这是本地注入验证，不是真实 DeepSeek供应商发生超时的观测证据。** 正常四工具及其他真实模型问题与这次注入分别记录。

Java本地完整验证 **188 项通过**，其中定向验证 **38 项通过**，覆盖错误分类、响应读取上限、异常内容不外泄、超时前没有副作用，以及导出提交后超时仍保留一个任务、原请求重试不再调用模型或重复导出。没有将这两个测试数重复相加。

## 独立只读审计与文件验证

网页操作结束后，在 Python服务仍正常运行时执行独立只读审计，**18 组检查全部通过**。审计登录合成账号，仅查询直接报表、助手历史、原请求结果和导出接口，并读取本轮数据库；不创建助手运行、不调用模型、不补做页面遗漏的业务写入。

审计确认本人汇总与直接报表一致，单日解释为 15/15 分钟且来源为 `CORRECTION`；部门导出条件正确，全库只有一个任务；该任务为 `READY`。受控 HTTP鉴权下载取得包含“说明、人员汇总、每日明细”的三页签 XLSX，说明页人数与十项统计均与部门报表预览一致。其他账号访问运行、任务或下载接口均收到业务 `403`；按原 `requestKey` 只读恢复得到同一运行和回执，没有重新 POST助手问题。

审计还核对模糊请求没有工具、注入超时分类正确、跨所有者任务查询被拒绝，以及失败场景后没有多余导出。审计前后模型账本未增加调用。合成文件和原始证据保存在被忽略的本地运行目录，不作为公开个人数据或生产材料发布。

浏览器曾实际点击“下载 Excel”，但自动化等待下载事件超时。因此，目前只确认网页存在可下载任务、下载动作已发起、受控 HTTP能下载正确文件；**浏览器是否完成最终保存尚未完全验证**。后续需要单独复核浏览器下载事件与实际落盘，不能用 HTTP文件校验替代这一项结论。
