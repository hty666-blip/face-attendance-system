# 人脸改造交付记录

日期：2026-10-23。保留 Vue 3、Java 8 语言目标、Spring Boot 2.7 与 MySQL。范围为本地人脸计算、受控模板管理与本人验证打卡，不包含 AI 助手、活体检测或完整考勤规则改造。

## 变更与取舍

1. 默认使用本地 YuNet 检测与 SFace 特征，三张样本录入，包含格式、大小、像素、单人、脸部尺寸、清晰度及光线检查。模型文件固定官方提交、大小与 SHA-256，准备阶段下载，运行阶段离线。
2. Python FastAPI 进程只负责检测、对齐、特征和余弦比对，不访问数据库。Java 负责身份权限、模板版本、阈值、验证会话和考勤事务，避免两种语言重复编排业务。
3. 本地模式只保存 AES-256-GCM 加密特征，密钥独立于 JWT；密文绑定员工、Provider、模型和模板版本。状态接口不返回照片、向量或密文。
4. 管理员按员工录入、撤销与迁移。旧照片由管理员逐人转换，只有新模板写入成功才在同一事务清除该员工旧明文照片；失败保留旧数据。重录增加模板版本；撤销清除该员工所有 Provider 的模板并递增版本，未完成旧会话标记 `INVALIDATED`。账号停用在同一事务清除所有模板和旧照片，并使未完成旧会话失效。
5. 本人打卡通过短期会话绑定当前账号、Provider、模板版本与请求指纹。成功原请求重试返回原考勤；并发只允许一个执行者。考勤写入与会话成功状态一起提交或回滚。中断后未完成的会话不直接放行。
6. 腾讯云保留为显式 Provider，无自动回退。腾讯云兼容模式使用加密参考图，与本地特征互不兼容；本地故障不会转为云上传。
7. 摄像头采集统一组件处理权限、加载、重拍、失败和关闭；启动/关闭竞态与晚到视频流需要释放轨道。前端呈现配置不足、质量失败、服务故障与未知网络结果，不把失败显示为已打卡。
8. 新增隔离环境准备、共享本地密钥初始化、人脸服务启动脚本及 Python CI。全部数据变更脚本手动执行，不自动修改真实数据库。

## 关键请求链路

- 录入：管理员与人员编辑权限 → 三张照片 → 本地质量检查及特征提取 → Java 校验 Provider/模型/响应 → AES-GCM 加密 → 短事务保存版本并清除旧照片。
- 验证：当前账号及打卡权限 → 本人有效模板 → 短期会话 → 占用会话 → 本地比对 → Java 阈值与会话/模板再校验 → 考勤与成功状态同事务提交。
- 重试：相同成功会话及请求指纹 → 返回原考勤编号；不同用户、不同请求内容、过期、撤销或模板变更 → 拒绝。
- 撤销：管理员与人员编辑权限 → 锁定该员工所有 Provider 模板 → 清密文、停用、增加版本并清旧照片 → 未完成旧会话标记 `INVALIDATED`。
- 账号停用：管理员权限及账号约束 → 停用账号并保留历史档案/考勤 → 同事务清除人脸模板和旧照片、使未完成旧会话失效。

## 运行与恢复

新库使用 `database/schema.sql` 与 `database/seed.sql`。旧库先备份，再在副本执行尚未执行的 V001、V002；V002 新建模板和会话表，不自动转换人脸。启动命令和环境变量见 README。

`.local/face-secrets.json` 不公开，初始化脚本不会覆盖已有文件。应安全备份数据库及对应模板密钥。模板密钥丢失后无法解密，需恢复原密钥或由管理员撤销并重新录入；不能通过新生成密钥恢复旧密文。内部通信令牌需要在 Java/Python 同步更新，不能单独更新一侧。

旧照片迁移会改变对应用户数据库内容，迁移前需要备份；备份自身仍可能包含明文人脸，需按敏感数据保存，不能提交仓库。源码回退与数据库恢复分别处理，DDL 的回退依赖备份。

## 已知限制

- 当前机器没有运行中的 MySQL 服务，未执行真实旧库迁移；需要在 MySQL 8 副本核对索引、事务、旧数据兼容和恢复。
- 没有活体检测。会话和幂等不能防止照片或视频重放；未声明可靠防代打卡。
- 定位来自浏览器上报，未做可靠位置防伪或地理围栏。打卡仍沿用现有中午划分规则，多个独立会话仍可能产生多次记录，完整班次与日级重复约束留待考勤流程阶段。
- 本地阈值 0.45 和质量参数为可调整初值，没有本项目人群误接收/误拒绝校准；公开样本同图比对、Mock 和单元测试不能证明真实识别精度。
- 一张旧照片迁移的模板覆盖面低于三张新采集，迁移后建议重新录入。Provider 或模型版本变化需重新登记匹配的模板。
- 未验证真实腾讯云账号状态，没有使用旧凭据发起真实云调用。腾讯云分值与质量规则不同于本地模式。
- 本地脚本只支持 Java/Python 同机回环通信。服务间令牌不替代异机部署所需的网络隔离与传输保护。
- 原始打卡事件、持久化完整操作审计、模型精度评测集、生产监控、可靠活体方案尚未建设。本轮成果不应被描述为可直接投产。
