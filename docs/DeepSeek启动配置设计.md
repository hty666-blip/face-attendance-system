# DeepSeek 显式启动配置

目标用户是维护本机考勤系统的开发者。用户填写本项目 `.local` 下的模型配置后，可显式传给 AI 启动脚本，避免把密钥复制到命令历史或意外提交公开仓库。

首版只增加 `start-ai.ps1 -ModelConfigPath <文件>`；不传参数保持原有环境变量流程，不自动读取私密文件、不自动启用模型或调用收费接口。内部服务令牌继续使用原有独立配置，Java 不接收模型 API Key。

文件限本项目 `.local` 内的普通本机文件；目录与文件均拒绝重解析点。通过 PowerShell AST 静态检查，只接受白名单环境变量到单引号静态字符串的赋值，拒绝执行代码、重复项、未知项、越界数值及外部追踪。通过全部检查后才临时注入启动进程，成功或失败均恢复调用者原有环境。错误仅返回固定说明，不带源文本、文件内容或凭据。

验收以独立合成配置运行离线测试：PowerShell 5.1 与 7 均验证合法读取、路径和语法拒绝、设置边界、错误脱敏以及启动失败后的环境恢复；测试不读取真实私密文件，不启动服务、数据库或模型调用。
